# 1Panel 部署问题清单

## 需要确认的问题

### 1. PostgreSQL 数据库
- **问题**：PostgreSQL 是否已在 1Panel 上安装？
- **说明**：项目需要 PostgreSQL 存储选课方案。可以用 1Panel 应用商店安装，或手动安装。
- **需要确认**：是否需要安装？如果已安装，版本是多少？

### 2. OIDC 登录服务
- **问题**：OIDC 登录服务是否已配置？
- **说明**：项目使用 Logto 作为 OIDC 登录服务。可以用 1Panel 应用商店安装，或手动安装。
- **需要确认**：
  - 是否需要安装 Logto？
  - 如果已安装，Logto 的 Issuer URL 和 Client ID 是什么？

### 3. 域名和 SSL
- **问题**：是否有域名和 SSL 证书？
- **说明**：项目需要域名和 SSL 证书才能访问。
- **需要确认**：
  - 是否有域名？
  - 是否需要配置 SSL 证书？

### 4. 服务器 IP
- **问题**：服务器 IP 地址是多少？
- **说明**：部署脚本中使用了 `10.0.0.2` 作为示例 IP。
- **需要确认**：实际的服务器 IP 地址是多少？

### 5. 部署目录
- **问题**：部署目录是否合适？
- **说明**：部署脚本中使用了 `/opt/mba-deploy` 作为部署目录。
- **需要确认**：是否需要在其他地方部署？

### 6. 端口配置
- **问题**：端口配置是否合适？
- **说明**：
  - `web` 容器使用 `7899` 端口
  - `mba-api` 容器使用 `3000` 端口
  - PostgreSQL 使用 `5432` 端口
- **需要确认**：是否需要在其他端口上部署？

### 7. 反向代理配置
- **问题**：反向代理配置是否合适？
- **说明**：
  - 1Panel 网站需要反向代理到 `http://10.0.0.2:7899`
  - 代理地址需要正确配置
- **需要确认**：
  - 是否需要配置反向代理？
  - 如果已配置，代理地址是否正确？

### 8. 版本更新
- **问题**：版本更新策略是否合适？
- **说明**：
  - 每次更新自动升 **小版本**：`v0.8.7` → `v0.8.8` … 以此类推，无需询问。
  - 较重大的 bug 修复或功能更新：可升 **次版本**：`v0.8.x` → `v0.9.0`。
  - **禁止**自行升至 `1.0.0`，需用户明确通知后方可升级。
- **需要确认**：是否需要自定义版本更新策略？

## 部署前检查清单

- [ ] PostgreSQL 已安装并配置
- [ ] OIDC 登录服务（如 Logto）已安装并配置
- [ ] 域名和 SSL 证书已配置
- [ ] 服务器 IP 地址已确认
- [ ] 部署目录已确认
- [ ] 端口配置已确认
- [ ] 反向代理配置已确认
- [ ] 版本更新策略已确认
