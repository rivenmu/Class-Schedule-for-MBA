# 回滚 (v0.8.0)

设计原则: API/Logto 任一挂掉, 站点降级为未登录模式, 浏览勾选 + Cookie + 离线下载全不受影响。

## 演练 (上线后做一次, 5 分钟)

1. 停 Node 运行环境 → `curl https://<你的站>/api/schemes` 应 502,
   页面方案面板显示“云端暂不可用”, 勾选/保存本地 HTML 照常。
2. 恢复启动 → 登录 → 方案列表回来。

## 真故障

- API 挂: 同上, 不用动前端, 修好 Node 即恢复 (云端数据在 PG 里, 不丢)。
- Logto 挂: 用户保持未登录态 (Cookie 照存), 修好后重新登录,
  暂存合并弹窗会再次出现 (以 `mba-merged` 会话 flag 为准, 关浏览器重开即重置)。
- PG 挂: API 500, 现象同 API 挂; 用 1Panel 数据库备份恢复 `mba` 库。
- 前端改坏: 静态站文件管理里把上一版 HTML 传回去即回滚 (建议覆盖前先下载备份)。
