- 📅 双学期可视化日历（2026 秋季 · 2027 春夏预测）

## 命名规范（便于扩展其他班级）
- 顶层班级文件夹：`{学校}{年级}MBA_{班级}`，如 `国科大26级MBA_全集班`、`国科大27级MBA_周末班`
- `source/` 存放教务处下发的原始 PDF/Excel，文件名保持 `{年份}{学期}-课程表.pdf`
- `dist/` 存放前端生成物，统一 `国科大{年级}级MBA_{班级}课表.html` 为当前主版本，历史版本 `archive-v*.html`
