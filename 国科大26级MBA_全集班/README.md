# 国科大26级MBA 全集班 -- 课程预选表

> 预览入口：`dist/index.html`（由原 `课程表v2.html` 重构）

## 目录
```
国科大26级MBA_全集班/
├── source/  # 元数据（原 PDF，逐字录入）
│   ├── 2025全日制集中班-课程表.pdf  # 2025-2026 春夏学期源表
│   └── 2026全日制集中班-课程表.pdf  # 2026-2027 秋季学期源表
├── dist/    # 生成物
│   ├── index.html        # 主版本（当前预选表，含可视化日历、冲突分组、学分统计）
│   └── archive-v1.html   # 归档 v1（原 课程表.html，保留作对比）
└── README.md
```

## 命名规范（便于扩展其他班级）
- 顶层班级文件夹：`{学校}{年级}MBA_{班级}`，如 `国科大26级MBA_全集班`、`国科大27级MBA_周末班`
- `source/` 存放教务处下发的原始 PDF/Excel，文件名保持 `{年份}{学期}-课程表.pdf`
- `dist/` 存放前端生成物，统一 `index.html` 为当前主版本，历史版本 `archive-v*.html`
