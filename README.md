## 功能简介

- 📅 双学期可视化日历（2026 秋季 · 2027 春夏预测）
- ✅ 课程勾选 + 类型筛选 + 冲突组分组（A-F / G-J 跨学期不重号）
- 📊 选课进度展示区：本学期选课比例、两学期学分汇总
- 💾 一键「保存选课下载 html」固化为本地文件，随时回看
- 📄 导出 PDF 便于打印共享

## 📱 移动端完美适配

本项目已全面适配手机浏览器，在 iPhone SE（320px）至 iPad（768px）及桌面端均可完美使用全部功能：

- **日历**：≤720px 自动切换为「每日时间线」视图（日期列 + 课程卡片），告别 7 列网格压扁
- **选课**：底部抽屉式面板，触控目标 ≥38px，筛选 / 勾选 / 冲突组全可用
- **已选课程列表**：≤720px 自动切换为卡片式布局，课程信息一目了然
- **弹窗**：手机端全屏底部弹出，支持安全区域（刘海 / 底部横条）
- **保存**：iOS Safari 下自动提示用分享菜单「存储到文件」；Android / 桌面直接下载
- **导出 PDF**：window.print 在移动浏览器上唤起系统打印对话框

## 扩展其他班级
- 复制 `国科大26级MBA_全集班/` 为同级新文件夹（如 `国科大27级MBA_周末班/`），内部同样 `source/` 放原始 PDF、`dist/` 放生成 HTML，并在上方下载区追加链接即可。
- 命名规范：
  - 班级文件夹：`{学校}{年级}MBA_{班级}`
  - 主文件名：`国科大{年级}级MBA_{班级}课表.html`
  - 历史版本：`archive-v*.html`
