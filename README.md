## 功能简介

- 📅 双学期可视化日历（2026 秋季 · 2027 春夏预测）
- 🔀 **七班切换**：表中间顶部位置选择班级，顶部下拉切换 全集班 / 综合班 / 非全日制集中班 / 人工智能与应用班 / 数字化转型与数字化创业班 / 脱产班 / 金融班，晚间选修课共享，白天课程按各班实际课表展示
- 🧭 **使用指引**：中间选班级，右上切学期，左侧选课——表中间顶部选班级，左侧课程勾选区按类型筛选勾选，右上角一键切换 2026 秋季 / 2027 春夏（预测）
- ✅ 课程勾选 + 5 类筛选（核心/必修/选修/暑期选修/专业，必修已合并原必选）+ 冲突组分组（A-F / G-J；脱产/金融等周六下午 K 组）
- 📊 选课进度展示区：本学期选课比例、两学期学分汇总
- 💾 一键「保存选课下载 html」固化为本地文件，随时回看
- 📄 导出 PDF 便于打印共享

## 扩展其他班级
- 七班共享同一 HTML 文件，通过顶部班级下拉切换器加载不同数据。新增班级只需：
  1. 在 `MBA-Schedule.html` 的 `CLASSES` 对象中追加新班级数据
  2. 在 header 的 `#classSelect` 下拉中追加 `<option>`
- 班级文件夹命名规范：`{学校}{年级}MBA_{班级}`
- 历史版本：`archive-v*.html`
